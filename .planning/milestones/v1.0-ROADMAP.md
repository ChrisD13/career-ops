# Milestone v1.0: JobEngine v2 MVP

**Status:** ✅ SHIPPED 2026-04-23
**Phases:** 1–3
**Total Plans:** 14

## Overview

JobEngine v2 layers three capabilities onto the existing file-backed job search system: (1) a secure Electron desktop app rendering tracker, reports, and pipeline data from the same canonical files the CLI uses; (2) direct Anthropic API integration with streaming evaluation, prompt caching, and mtime-based context deduplication; and (3) a VC portfolio discovery pipeline that scrapes 10 leading VC firm portfolios, filters by recent funding and active role listings, and surfaces promoted companies into the pipeline — all from a 6-panel desktop app.

## Milestone Summary

**Key Decisions:**
- Electron + Anthropic API directly: enables prompt caching + streaming without CLI dependency — ✓ Good
- Live VC portfolio scraping via Playwright: handles SPA hydration, graceful degrade on selector drift — ✓ Good
- Preserve file-backed state (no DB): lockAndWrite + write-file-atomic proved safe in 104-write stress tests — ✓ Good
- per-runId onExit lock release in scheduler: cleaner than global activeOpsCount polling — ✓ Good (WR-01 fix from code review)

**Issues Resolved:**
- Concurrent write corruption risk — solved with proper-lockfile + write-file-atomic + pendingGuiWrites suppression
- Prompt cache context bloat — solved with mtime-based deduplication (data/.mtime-cache.json)
- Scraper lock contention — solved with single-flight scrapeActive flag + onExit release per startOp runId

**Technical Debt Incurred:**
- Human UAT deferred for Phases 2 and 3 (48 total items across both phases)
- 3 info-level code review items: null guard on --firm filter, DEFAULT_VC_INTERVAL import, loop-index mutation in accel/coatue adapters
- VC adapter selector drift likely for 8 of 10 firms on first real scrape
- npm install required at project root before running scrape-vcs.mjs (package.json declares deps, node_modules not committed)
