<objective>
Eliminate launcher friction on Linux: after first run of the packaged AppImage, JobEngine appears in the user's system launcher exactly like a natively installed app, and subsequent launches never modify the entry the user may have customized.

Purpose: Closes DESK-01 (create ~/.local/share/applications/jobengine.desktop on first packaged run) and DESK-02 (idempotent — never overwrite). This is a one-shot main-process side-effect — no UI, no IPC, no preload bridge change, no new dependency. The entire feature is one new file (~50 lines) plus a one-line wiring edit in index.ts.

Output:
- New: electron/src/main/services/desktop-shortcut.ts (exports ensureDesktopShortcut)
- Modified: electron/src/main/index.ts (import + call site after setTimeout(initUpdater))
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AppImage runtime → Electron main process | `process.env.APPIMAGE` and `process.env.APPDIR` cross this boundary. The AppImage runtime is part of the trusted base (we ship the AppImage); env vars are not user-supplied input. |
| Electron main → user filesystem (`~/.local/share/...`) | The user's home directory is the user's trust boundary. We write only files we own and never read user-modified content back. |
| Electron main → desktop environment | The DE parses the `.desktop` file. Our content is fixed strings + `process.env.APPIMAGE`; no user input is interpolated. |
| (no renderer involvement — phase has no IPC surface) | — |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering / Elevation (shell injection via Exec= path) | `buildDesktopEntry()` Exec line | mitigate | Wrap `${appImagePath}` in literal double quotes — `Exec="${appImagePath}"`. The DE tokenizer respects quotes per [specifications.freedesktop.org/desktop-entry/latest/exec-variables.html](https://specifications.freedesktop.org/desktop-entry/latest/exec-variables.html). Defense-in-depth: even though `$APPIMAGE` originates from the trusted AppImage runtime, paths can contain spaces; without quoting the launcher would split tokens (Pitfall 2). Acceptance criterion #3 enforces this literally. |
| T-07-02 | Information disclosure / corruption (partial write of `.desktop` file) | `writeFileAtomic(target, entry, { mode: 0o644 })` | mitigate | `write-file-atomic@7.0.1` writes via tmp + rename + fsync (project standard, Phase 2 decision).
