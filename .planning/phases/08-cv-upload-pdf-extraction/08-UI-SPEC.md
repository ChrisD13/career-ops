## Color

Project palette: Catppuccin Mocha. Token values from `electron/src/renderer/styles/globals.css`.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `ctp-base` | `#1e1e2e` | All panel backgrounds, modal backdrop fill |
| Secondary (30%) | `ctp-surface` | `#313244` | Modal card, panel headers, form inputs on darker bg |
| Border / inactive | `ctp-overlay` | `#45475a` | Borders, dividers, secondary button background |
| Text primary | `ctp-text` | `#cdd6f4` | All readable content |
| Text secondary | `ctp-subtext` | `#a6adc8` | Labels, captions, placeholder |
| Accent (10%) | `ctp-mauve` | `#cba6f7` | **Confirm (Replace) button ONLY** — reserved for the single destructive-forward action |
| Destructive | `ctp-red` | `#f38ba8` | Inline error banners, extraction failure message |

### Accent reserved for

`ctp-mauve` is the existing project accent used on primary-action buttons (Regenerate PDF, Export LaTeX, Save Firm, etc.). For Phase 8 it is reserved for: **the "Replace" confirmation button in the confirmation modal only**. This is consistent with all other modals in the codebase (AddFirmModal "Save Firm").

**Rationale for mauve on Replace, not red:** The confirmation dialog already surfaces the last-modified date and requires an explicit two-step journey (pick file → confirm). That two-step flow is the safeguard. Marking Replace red would imply the action can be taken in a single click — it cannot. The mauve "Replace" label (coupled with the modal's own warning copy) is the correct signal weight.

### "Update CV" button (secondary)

The CONTEXT.md explicitly requires "Update CV" to be **visually secondary** to Regenerate PDF and Export LaTeX. Do NOT use `ctp-mauve` for this button.

Required Tailwind classes:
```
bg-ctp-overlay text-ctp-text border border-ctp-overlay rounded px-3 py-1 text-label
hover:bg-ctp-overlay/70 disabled:opacity-50
```

This matches the `pipeline-panel__action` (non-primary) pattern already in the codebase — a `bg-ctp-overlay` secondary action button in a panel header row.

## Interaction States

### "Update CV" Button (CvPanel header)

| State | Appearance |
|-------|------------|
| Idle | `bg-ctp-overlay text-ctp-text` |
| Picker open / file loading | `disabled:opacity-50 cursor-wait` — button text: "Opening…" |
| PDF extracting | `disabled:opacity-50 cursor-wait` — button text: "Extracting…" |

### PDF Review Modal (CvUploadModal)

Opens after successful extraction. Textarea is pre-filled with extracted Markdown; user can edit freely before confirming.

| Element | Detail |
|---------|--------|
| Modal width | 600px (wider than AddFirmModal's 480px — textarea needs room) |
| Textarea height | min 320px, scrollable |
| Extraction error | Inline below textarea — `bg-ctp-red/15 border border-ctp-red text-ctp-red text-body` |
| Cancel | `text-label text-ctp-subtext hover:text-ctp-text` — plain text button (matches AddFirmModal) |
| Continue / Next | `bg-ctp-overlay text-ctp-text text-label` — advances to confirmation dialog |

### Confirmation Modal (CvConfirmModal)

Appears for BOTH `.md` and `.pdf` paths. Shows current `cv.md` last-modified date.

| Element | Detail |
|---------|--------|
| Modal width | 400px |
| Last-modified display | `text-body text-ctp-subtext` — format: `YYYY-MM-DD HH:mm` (project convention) |
| Cancel | `text-label text-ctp-subtext hover:text-ctp-text` |
| Replace | `bg-ctp-mauve text-ctp-base text-label px-3 py-1 rounded` (matches Save Firm) |
| Replace (saving) | `disabled:opacity-50` — label: "Saving…" (matches AddFirmModal) |
| Replace (done) | Modal closes; CvPanel re-reads `cv.md` via `readCv()` — no extra toast |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (Update CV button) | **Update CV** |
| PDF review modal title | **Review Extracted CV** |
| Confirmation modal title | **Replace cv.md?** |
| Confirmation modal body | `This will overwrite your current CV. Last modified: {YYYY-MM-DD HH:mm}` |
| Replace button | **Replace** |
| Cancel button | **Cancel** |
| Continue to confirm button | **Continue** |
| In-flight: picker open | **Opening…** (button label) |
| In-flight: PDF extract | **Extracting…** (button label) |
| In-flight: saving | **Saving…** (Replace button label in confirm modal) |
| Empty state | Not applicable — "Update CV" is invoked from an existing populated panel; there is no empty state for the upload flow itself |
| Error: PDF extraction failed | **Could not extract text from PDF. Try a text-based PDF.** (source: CONTEXT.md decision) |
| Error: file read failed | **Could not read file. Check it exists and try again.** |
| Error: write failed | **Failed to save CV. Check permissions and try again.** (mirrors `Failed to save` in AddFirmModal) |

Destructive actions in this phase:

| Action | Approach |
|--------|----------|
| Replace cv.md | Two-step modal flow (pick/review → confirm). Confirmation modal shows last-modified date. Dedicated "Replace" button — no accidental submit. |
