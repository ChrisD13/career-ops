### Step A — Add the a16z bake-resolved-attributes branch to `validate-adapters.mjs --capture`

In `validate-adapters.mjs`, inside the `if (captureFlag) { ... }` block (currently around lines 82-98), BEFORE `const html = await page.content();`, insert an a16z-specific page-side evaluation that (1) reads the resolved aria-label on every matching card button via the `ariaLabel` IDL property (which evaluates Alpine bindings live), (2) writes that resolved value back as a static `aria-label="..."` attribute, AND (3) removes the raw Alpine directive source attribute `:aria-label` so it cannot re-trigger on replay.

Recommended implementation (adapt if needed to pass the acceptance criteria below):

```javascript
if (captureFlag) {
  const filename = FIXTURE_FILENAMES[firm.name] ?? `${firm.name.toLowerCase().replace(/\s+/g, '-')}.html`;
  const page = await ctx.newPage();
  try {
    await page.goto(firm.portfolio_url, { waitUntil: 'domcontentloaded', timeout: 60000 });
    await page.waitForTimeout(5000);

    // a16z-specific: Alpine.js binds aria-label via `:aria-label="item.company.name"`.
    // page.content() serializes the DIRECTIVE SOURCE, not the resolved attribute value,
    // so the replayed fixture errors out on offline re-evaluation. Bake the resolved
    // value into a static attribute and remove the Alpine directive so replay is inert.
    if (firm.name === 'a16z') {
      const baked = await page.evaluate(() => {
        const nodes = document.querySelectorAll('button.group\\/card, [x-on\\:click*="triggerModal"]');
        let count = 0;
        for (const el of nodes) {
          // `ariaLabel` IDL reads the resolved attribute value from the live Alpine-hydrated DOM.
          const resolved = (el.ariaLabel || el.getAttribute('aria-label') || '').trim();
          if (resolved && !resolved.includes('item.company')) {
            el.setAttribute('aria-label', resolved);
            count++;
          }
          // Neutralize Alpine directive sources that would re-fire on offline replay.
          for (const attrName of [':aria-label', 'x-bind:aria-label']) {
            if (el.hasAttribute(attrName)) el.removeAttribute(attrName);
          }
        }
        // Also strip the Alpine runtime so the replay browser does not try to mount wr25Portfolio().
        for (const s of document.querySelectorAll('script[src*="alpine"], script[x-data], script[data-alpine]')) {
          s.remove();
        }
        return count;
      });
      console.log(`  a16z: baked ${baked} aria-label attributes, stripped Alpine directives`);
    }

    const html = await page.content();
    mkdirSync(FIXTURE_DIR, { recursive: true });
    writeFileSync(`${FIXTURE_DIR}/${filename}`, html);
    console.log(`  Fixture saved: ${FIXTURE_DIR}/${filename} (${html.length} bytes)`);
  } finally {
    await page.close();
  }
}
```

Do NOT wrap the other 8 firms in this branch — their adapters work fine and their fixtures have no Alpine directives. The check `if (firm.name === 'a16z')` must gate the bake.
