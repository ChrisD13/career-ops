# Requirements Archive — v1.2 Setup & CV Management

**Archived:** 2026-04-27
**Status:** ✅ Shipped — all requirements satisfied at code level (DESK-01 UAT-deferred)

## Desktop Shortcut

- [x] **DESK-01** — App creates `~/.local/share/applications/jobengine.desktop` on first launch (packaged build only), enabling the app to appear in the system launcher
  - **Outcome:** Structurally satisfied — `existsSync` gate + `writeFileAtomic` + correct `Exec=`/`Icon=`/`StartupWMClass=` fields. End-to-end UAT deferred to first packaged AppImage build.
- [x] **DESK-02** — Shortcut creation is idempotent: skips silently if the `.desktop` file already exists, never overwrites user modifications
  - **Outcome:** Fully satisfied — `if (existsSync(target)) return` at line 44 is the only code path. No `readFile` on target, no content comparison, no conditional overwrite. Verified in code.

## CV Management

- [x] **CV-01** — User can open a file picker from within the app and select a `.md` or `.pdf` file to replace `cv.md`
  - **Outcome:** Satisfied — `openCvFilePicker` IPC handler + native `dialog.showOpenDialog` with `.md`/`.pdf` filter + `CvPanel` "Update CV" button wired end-to-end.
- [x] **CV-02** — When a `.md` file is selected, its content replaces `cv.md` directly with no conversion
  - **Outcome:** Satisfied — `.md` branch reads file as UTF-8, passes directly to `updateCv`; no conversion step. Human UI flow UAT deferred.
- [x] **CV-03** — When a `.pdf` file is selected, its text content is extracted and written to `cv.md` as plain Markdown
  - **Outcome:** Satisfied — `extractPdfText()` via `unpdf@1.6.0`; result written via `updateCv` → `lockAndWrite`. Human UI flow UAT deferred.
- [x] **CV-04** — After PDF extraction, user sees the converted Markdown in a review pane and can edit it before saving
  - **Outcome:** Satisfied (code) — `CvUploadModal` with editable monospace textarea (600px wide, 320px min height); `.pdf` branch → `kind: 'review'`. Human visual UAT deferred.
- [x] **CV-05** — User sees a confirmation prompt before overwrite showing the current `cv.md` last-modified date
  - **Outcome:** Satisfied (code) — `CvConfirmModal` shows `Last modified: {formatMtime(mtimeIso)}`; mtime fetched at modal-open time. Human visual UAT deferred.
